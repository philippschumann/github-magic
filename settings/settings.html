Repos

    The buttons work on these GitHub repos. Add… asks for the repo's main clone on this Mac and reads the repo from its origin. Run on phone and emulator need the Android app ID, Run on iPhone and simulator the Xcode scheme.

    New PR worktrees are created here as <repo>-<branch>. Until it is set, the IDE button only offers "Set up".

    "Open in" uses this IDE for Android repos. Only installed IDEs are listed. Until one is chosen, the IDE button asks.

    "Open in" uses this IDE for iOS repos. Only installed ones are listed. Until one is chosen, the IDE button asks.

    "Run on emulator" uses this emulator and boots it if it isn't running. Until one is chosen, it asks.

    "Run on simulator" uses this iOS simulator and boots it if it isn't running. Until one is chosen, it asks.

    "Run on phone" prefers the connected phones in this order, then any other. One per line, as adb devices -l shows them, for example model:Pixel_10.
